1. Gambaran proyek

SIMPUS-Mini adalah aplikasi perpustakaan sederhana untuk melihat daftar buku dan anggota, mencari data, menghapus baris, dan mengisi form tambah data.

  • HTML membentuk kerangka lima halaman.
  • CSS (style.css) mengatur tampilan: warna cokelat, card, tabel, form, dan layout responsif.
  • JavaScript mengambil data dari file JSON, membuat baris tabel, menjalankan pencarian, konfirmasi hapus, validasi form, dan menu hamburger.

Karena memakai fetch(), proyek harus dibuka lewat server lokal (misalnya ekstensi Live Server di VS Code). Jika dibuka langsung dengan file://, data tidak akan tampil.

Input pada form

  • Atribut required membuat browser menolak field kosong.
  • type="number" dengan min dan max membatasi angka (tahun 1900–2026, stok minimal 0).
  • <label for="x"> harus sama dengan id="x" pada input supaya label bisa diklik.

    display: flex;

Kartu Ringkasan dengan nth-of-type

main section:nth-of-type(2) memilih <section> kedua di dalam <main>, yaitu bagian "Ringkasan" di Beranda. Di halaman lain hanya ada satu section sehingga aturan ini tidak berpengaruh.

main section:nth-of-type(2) {
    display: flex;
    flex-direction: column;   /* kartu tersusun atas ke bawah */
    gap: 1rem;
}
main section:nth-of-type(2) article {
    display: flex;
    align-items: center;
    justify-content: space-between;  /* judul kiri, angka kanan */
    min-height: 100px;
}

Tombol Edit & Hapus

JavaScript membuat dua tombol per baris. Warnanya ditentukan posisi, bukan class:

  • td button:first-of-type → Edit (oranye)
  • td button:last-of-type → Hapus (merah)

Breakpoint responsive

Lebar layarPerubahan
≤ 768px (tablet)Padding main mengecil, kartu ringkasan lebih pendek
≤ 480px (HP)Navbar disembunyikan dan muncul lewat hamburger; menu vertikal; angka ringkasan mengecil; input memenuhi lebar layar

Hamburger menu

  • .nav-toggle-label disembunyikan di desktop (display: none) dan ditampilkan di HP.
  • Di HP, header nav disembunyikan. Class nav-open yang ditambahkan JavaScript menampilkannya kembali (header nav.nav-open { display: block; }).
  • Cara lama (checkbox .nav-toggle:checked ~ nav) masih ada di CSS dan dipakai oleh index.html.

6. Panduan JavaScript

app.js — fungsi umum (semua halaman)

FungsiTugas
initNavToggle()Klik tombol hamburger → nav.classList.toggle("nav-open")
initHapusConfirm()Event delegation pada document. Klik .btn-hapus → confirm() → jika Ya, baris dihapus dengan row.remove()
initTableFilter()Setiap keyup di #search-input, baris yang teksnya tidak mengandung kata kunci disembunyikan
initValidasiForm()Saat submit, cek field wajib, tahun (1900–2026), dan stok (≥ 0). Jika ada yang salah, e.preventDefault()
tampilkanError() / hapusError()Membuat dan menghapus <span class="error"> tepat setelah input

Semua fungsi init... dipanggil sekali di DOMContentLoaded.

Kenapa event delegation? Tombol Hapus dibuat belakangan oleh fetch, jadi belum ada saat halaman selesai dimuat. Listener dipasang di document lalu dicek dengan e.target.closest(".btn-hapus").

buku.js dan anggota.js — memuat tabel

Keduanya punya pola yang sama:

  1. Tampilkan "Memuat data..." dan kosongkan <tbody>.
  2. Tunggu 600 ms (simulasi loading) dengan setTimeout di dalam Promise.
  3. fetch("../data/....json"); jika res.ok salah, lempar error.
  4. Untuk setiap data, buat <tr> berisi sel data dan tombol Edit/Hapus, lalu appendChild.
  5. catch menampilkan pesan gagal di tabel; finally selalu menyembunyikan loading.
pola async/await 
async function muatDaftarBuku() {
    try {
        const res  = await fetch("../data/buku.json");
        if (!res.ok) throw new Error("status " + res.status);
        const data = await res.json();
        data.forEach(function (buku) { /* buat baris tabel */ });
    } catch (err) {
        /* tampilkan pesan error */
    } finally {
        /* sembunyikan loading */
    }
}
document.addEventListener("DOMContentLoaded", muatDaftarBuku);

8. Alur kerja aplikasi

Membuka Daftar Buku

  1. Browser memuat buku/list.html dan style.css.
  2. app.js dan buku.js dijalankan setelah DOM siap.
  3. buku.js mengambil buku.json dan mengisi tabel.
  4. Pengguna mengetik di kotak cari → baris disaring langsung.
  5. Pengguna klik Hapus → muncul konfirmasi → baris hilang dari tampilan.

Mengisi form Tambah

  1. Pengguna mengisi form dan klik Simpan.
  2. Browser mengecek atribut required, min, max.
  3. initValidasiForm() mengecek lagi; jika salah, pesan merah muncul dan submit dibatalkan.
