# 5. File `index.html`

| No. | Kode | Penjelasan |
|---:|---|---|
| 1 | `<!DOCTYPE html>` | Menentukan bahwa dokumen menggunakan standar HTML5. |
| 2 | `<html lang="id">` | Membuka dokumen HTML dan menentukan bahasa halaman sebagai Bahasa Indonesia. |
| 3 | `<head>` | Membuka bagian head dokumen. |
| 4 | `<meta charset="UTF-8">` | Menentukan encoding karakter UTF-8. |
| 5 | `<title>SIMPUS-Mini \| Beranda</title>` | Menentukan judul halaman yang ditampilkan pada tab browser. |
| 6 | `</head>` | Menutup bagian head. |
| 7 | `<body>` | Membuka bagian body yang berisi konten halaman. |
| 8 | `<header>` | Membuka bagian header website. |
| 9 | `<h1>SIMPUS-Mini</h1>` | Menampilkan judul utama website. |
| 10 | `<nav>` | Membuka bagian navigasi. |
| 11 | `<ul>` | Membuat daftar menu navigasi. |
| 12 | `<li><a href="index.html">Beranda</a></li>` | Membuat menu Beranda yang mengarah ke halaman utama. |
| 13 | `<li><a href="buku/list.html">Daftar Buku</a></li>` | Membuat menu untuk menuju daftar buku. |
| 14 | `<li><a href="buku/tambah.html">Tambah Buku</a></li>` | Membuat menu untuk menuju halaman tambah buku. |
| 15 | `<li><a href="anggota/list.html">Daftar Anggota</a></li>` | Membuat menu untuk menuju daftar anggota. |
| 16 | `</ul>` | Menutup daftar menu. |
| 17 | `</nav>` | Menutup navigasi. |
| 18 | `</header>` | Menutup header. |
| 19 | `<main>` | Membuka bagian utama halaman. |
| 20 | `<section>` | Membuka section pertama. |
| 21 | `<h2>Selamat Datang di Sistem Perpustakaan Mini</h2>` | Menampilkan judul sambutan untuk pengguna. |
| 22 | `<p>Aplikasi sederhana untuk mengelola data buku dan anggota perpustakaan.</p>` | Menampilkan deskripsi singkat mengenai fungsi aplikasi. |
| 23 | `</section>` | Menutup section pertama. |
| 24 | `<section>` | Membuka section kedua untuk ringkasan data. |
| 25 | `<h2>Ringkasan</h2>` | Menampilkan judul bagian ringkasan. |
| 26 | `<article>` | Membuka article untuk informasi total buku. |
| 27 | `<h3>Total Buku</h3>` | Menampilkan label Total Buku. |
| 28 | `<p>12</p>` | Menampilkan jumlah total buku, yaitu 12. |
| 29 | `</article>` | Menutup article Total Buku. |
| 30 | `<article>` | Membuka article untuk informasi total anggota. |
| 31 | `<h3>Total Anggota</h3>` | Menampilkan label Total Anggota. |
| 32 | `<p>8</p>` | Menampilkan jumlah total anggota, yaitu 8. |
| 33 | `</article>` | Menutup article Total Anggota. |
| 34 | `<article>` | Membuka article untuk informasi buku yang sedang dipinjam. |
| 35 | `<h3>Sedang Dipinjam</h3>` | Menampilkan label jumlah buku yang sedang dipinjam. |
| 36 | `<p>3</p>` | Menampilkan jumlah buku yang sedang dipinjam, yaitu 3. |
| 37 | `</article>` | Menutup article buku yang sedang dipinjam. |
| 38 | `</section>` | Menutup section ringkasan. |
| 39 | `</main>` | Menutup bagian utama halaman. |
| 40 | `<footer>` | Membuka bagian footer website. |
| 41 | `<p>&copy; 2026 SIMPUS-Mini &mdash; Jobsheet 1</p>` | Menampilkan copyright dan informasi jobsheet. |
| 42 | `</footer>` | Menutup footer. |
| 43 | `</body>` | Menutup bagian body. |
| 44 | `</html>` | Menutup dokumen HTML. |
