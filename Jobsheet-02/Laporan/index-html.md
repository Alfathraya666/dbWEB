# Penjelasan Per-Line `index.html`

| No. | Kode | Penjelasan |
|---:|---|---|
| 1 | `<!DOCTYPE html>` | Mendeklarasikan bahwa dokumen menggunakan HTML5. |
| 2 | `<html lang="id">` | Membuka elemen HTML dan menentukan bahasa halaman sebagai Bahasa Indonesia (`id`). |
| 3 | `<head>` | Membuka bagian head yang berisi informasi dan konfigurasi halaman. |
| 4 | `<meta charset="UTF-8">` | Menentukan karakter encoding UTF-8 agar berbagai karakter dan simbol dapat ditampilkan dengan benar. |
| 5 | `<title>SIMPUS-Mini \| Beranda</title>` | Menentukan judul halaman yang akan ditampilkan pada tab browser. |
| 6 | `<link rel="stylesheet" href="assets/style.css">` | Menghubungkan file HTML dengan file CSS `style.css` yang berada di folder `assets`. |
| 7 | `</head>` | Menutup bagian `<head>`. |
| 8 | `<body>` | Membuka bagian body yang berisi seluruh konten yang ditampilkan pada halaman website. |
| 9 | `<header>` | Membuka bagian header atau bagian kepala website. |
| 10 | `<h1>SIMPUS-Mini</h1>` | Menampilkan judul utama website dengan heading tingkat 1. |
| 11 | `<nav>` | Membuka bagian navigasi yang berisi menu-menu website. |
| 12 | `<ul>` | Membuat daftar tidak berurutan untuk menampung menu navigasi. |
| 13 | `<li><a href="index.html">Beranda</a></li>` | Membuat menu Beranda. Tag `<a>` digunakan sebagai link yang mengarah ke `index.html`. |
| 14 | `<li><a href="buku/list.html">Daftar Buku</a></li>` | Membuat menu Daftar Buku yang mengarah ke halaman `list.html` di dalam folder `buku`. |
| 15 | `<li><a href="buku/tambah.html">Tambah Buku</a></li>` | Membuat menu Tambah Buku yang mengarah ke halaman `tambah.html` di dalam folder `buku`. |
| 16 | `<li><a href="anggota/list.html">Daftar Anggota</a></li>` | Membuat menu Daftar Anggota yang mengarah ke halaman `list.html` di dalam folder `anggota`. |
| 17 | `</ul>` | Menutup daftar menu `<ul>`. |
| 18 | `</nav>` | Menutup bagian navigasi. |
| 19 | `</header>` | Menutup bagian header website. |
| 20 | `<main>` | Membuka bagian utama halaman website. |
| 21 | `<section>` | Membuka section pertama yang digunakan untuk bagian sambutan atau informasi utama. |
| 22 | `<h2>Selamat Datang di Sistem Perpustakaan Mini</h2>` | Menampilkan judul section dengan heading tingkat 2. |
| 23 | `<p>Aplikasi sederhana untuk mengelola data buku dan anggota perpustakaan.</p>` | Menampilkan paragraf yang menjelaskan fungsi aplikasi. |
| 24 | `</section>` | Menutup section pertama. |
| 25 | `<section>` | Membuka section kedua yang digunakan untuk menampilkan ringkasan atau statistik. |
| 26 | `<h2>Ringkasan</h2>` | Menampilkan judul "Ringkasan" menggunakan heading tingkat 2. |
| 27 | `<article>` | Membuka elemen article pertama untuk menampilkan satu informasi statistik. |
| 28 | `<h3>Total Buku</h3>` | Menampilkan judul statistik yang menunjukkan jumlah total buku. |
| 29 | `<p>12</p>` | Menampilkan jumlah total buku, yaitu 12. |
| 30 | `</article>` | Menutup article pertama. |
| 31 | `<article>` | Membuka article kedua untuk menampilkan statistik anggota. |
| 32 | `<h3>Total Anggota</h3>` | Menampilkan judul statistik yang menunjukkan jumlah anggota. |
| 33 | `<p>8</p>` | Menampilkan jumlah total anggota, yaitu 8. |
| 34 | `</article>` | Menutup article kedua. |
| 35 | `<article>` | Membuka article ketiga untuk menampilkan statistik peminjaman. |
| 36 | `<h3>Sedang Dipinjam</h3>` | Menampilkan judul statistik mengenai buku yang sedang dipinjam. |
| 37 | `<p>3</p>` | Menampilkan jumlah buku yang sedang dipinjam, yaitu 3. |
| 38 | `</article>` | Menutup article ketiga. |
| 39 | `</section>` | Menutup section kedua yang berisi ringkasan. |
| 40 | `</main>` | Menutup bagian utama halaman website. |
| 41 | `<footer>` | Membuka bagian footer atau bagian bawah website. |
| 42 | `<p>&copy; 2026 SIMPUS-Mini &mdash; Jobsheet 1</p>` | Menampilkan informasi copyright tahun 2026, nama website, dan keterangan Jobsheet 1. `&copy;` menghasilkan simbol © dan `&mdash;` menghasilkan tanda em dash (—). |
| 43 | `</footer>` | Menutup bagian footer. |
| 44 | `</body>` | Menutup seluruh isi halaman yang ditampilkan pada browser. |
| 45 | `</html>` | Menutup dokumen HTML. |
